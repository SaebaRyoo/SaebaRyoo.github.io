关于查看React源码使用flow，却提示ts类型检查的错误

# vscode
信件目录
  1. 问题
  2. 解决

问题

在看 React 源码时，因为 React 使用的是 flow,但是一直会报 TS 的类型错误

解决

首先是查询到了先要安装 flow 的扩展Flow Language Support，然后又下载了 flowbrew install flow，又在设置中修改了 flow 的 path/usr/local/bin/flow。但是还报错

最后再 Stack Overflow 找到了另一种方式

在 VSCode 的工作区设置如下，关闭了当前项目的 ts 类型报错和 js 的验证

{
  "typescript.validate.enable": false,
  "javascript.validate.enable": false
}
