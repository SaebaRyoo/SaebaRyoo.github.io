# Claude Code 免费接入 DeepSeek V4 教程（零成本爽用）

## 第一步：获取 API Key

可选择以下两个平台，均提供免费额度：

* ​**阿里云百炼**​：V4 Flash 和 Pro 各提供 **100 万 token** 免费额度
  [bailian.console.aliyun.com](https://bailian.console.aliyun.com/)
* ​**魔塔社区（ModelScope）**​：日均 ​**2000 次免费调用**​，单模型日均限 500 次
  [modelscope.cn/home](https://modelscope.cn/home)

## 第二步：下载 CC Switch 并新建供应商

CC Switch 是一个方便切换不同供应商的桌面工具。

* 下载地址：[https://github.com/farion1231/cc-switch](https://github.com/farion1231/cc-switch)

使用步骤：

1. 下载并启动 CC Switch
2. 新建供应商，从预设中选择 **Bailian** 或 **ModelScope**
3. 把对应平台的 API Key 粘贴进去

## 第三步：配置模型

按需求填写模型配置。示例：

* ​**主模型**​：V4 Flash
* ​**Opus 模型**​：V4 Pro

⚠️ ​**重要提示**​：默认只有 ​**200K 上下文**​，若需 ​**1M 上下文**​，必须在模型名后面添加 `[1m]`

### 不同平台的模型名写法

​**阿里云百炼**​：



```text
deepseek-v4-flash[1m]
deepseek-v4-pro[1m]
```

​**魔塔社区（ModelScope）**​：



```text
deepseek-ai/DeepSeek-V4-Flash[1m]
deepseek-ai/DeepSeek-V4-Pro[1m]
```

## 第四步：保存配置，打开 Claude Code 即可使用

完成以上配置后，保存设置，启动 Claude Code 即可零成本使用 DeepSeek V4。
